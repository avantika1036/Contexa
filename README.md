# Contexa

A real-time AI copilot that builds structured meeting memory to help
participants recover context, track decisions, and get grounded answers
during live discussions.

## Status

Initial development: frontend scaffold established.

## Technology Stack

- React + TypeScript
- Python + FastAPI
- WebSockets
- PostgreSQL + pgvector
- Streaming speech-to-text
- LLM-powered retrieval and answering

## Planned MVP

1. Real-time audio capture and transcription
2. Incremental structured meeting memory
3. Context-grounded question answering
4. Meeting context recovery
